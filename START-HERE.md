## 🎯 WHAT THIS DEMO DOES

A fully working demonstration of **three-stage quality monitoring** for AI agents:

```
Stage 1: Local Development (15 min)
  ├─ Interactive agent testing
  ├─ OpenTelemetry traces captured
  ├─ Instant evaluation feedback
  └─ Developer iterates immediately

Stage 2: CI/CD Pipeline (20 min)
  ├─ Automated batch evaluation
  ├─ Quality gates checked
  ├─ PR blocks if quality drops
  └─ Prevents bad code shipping

Stage 3: Production Monitoring (15 min)
  ├─ Continuous real-world monitoring
  ├─ 10% sampling (cost optimization)
  ├─ Drift detection alerts
  └─ On-call response workflow
```
